# 版本记录

本文件记录 `modern-vue-admin` 的发布版本和主要变化。版本号遵循语义化版本规则。

## [1.0.0] - 2026-09-15

### 初始化版本

- 以 `modern-vue-admin` 作为项目名称建立本地 Git 仓库。
- 提供基于 Vue 3、TypeScript、Vite 和 Element Plus 的管理后台基础结构。
- 提供仪表盘、用户管理、表单、多级菜单和文档页面模板。
- 提供本地 Mock 服务、动态菜单、环境变量和 API 代理配置。
- 提供类型检查、代码检查、格式检查和生产构建命令。
- 使用 npm 和 `package-lock.json` 管理依赖版本。
